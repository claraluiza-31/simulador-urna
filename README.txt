SIMULADOR DE URNA — VERSÃO WEB

Arquivos:
- index.html: aplicativo completo
- manifest.json: permite instalar como PWA
- service-worker.js: base para funcionamento como aplicativo web

Como testar:
1. Abra index.html no computador para testar.
2. Para instalar no celular como aplicativo, publique estes arquivos em um endereço HTTPS (GitHub Pages, Netlify, Vercel ou outro serviço de hospedagem).
3. Abra o endereço no celular e use "Adicionar à Tela de Início".

Os candidatos e fotos são armazenados localmente no navegador (localStorage). Esta versão é uma simulação e não registra votos reais.
